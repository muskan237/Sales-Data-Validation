
# Sales-Data-Validation

Sales data validation and cleaning project using Excel and Power BI. Focused on identifying duplicates, missing values, and data inconsistencies to ensure 100% accurate reporting.

**Tools Used:** Excel, Power BI

**Key Tasks:**
- Data cleaning and validation checks
- Duplicate and null value detection 
- Revenue and quantity consistency checks
